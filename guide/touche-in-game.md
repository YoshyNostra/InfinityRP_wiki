# 🪙 Touche In-Game

Liste des touches et raccourcis utiles en jeu sur InfinityRP.

| Touche | Action |
|---|---|
| `F1` | Ouvrir le téléphone |
| `F2` | Ouvrir l'inventaire |
| `F3` | Ouvrir le menu des animations |
| `E` | Interagir |
| `M` | Ouvrir la carte |
| `T` | Chat écrit |
| `N` | Chat proximité vocal (Push-to-talk selon config) |

> Cette liste est indicative — pense à l'adapter aux touches réellement configurées sur InfinityRP (HUD, inventaire, etc.).
