# ⚙️ Map qui ne charge pas

Si la map (les ajouts custom du serveur) ne se charge pas correctement, voici les solutions à essayer dans l'ordre.

## Solutions

1. **Vide ton cache FiveM** (voir la page [Vider son cache Fivem](vider-cache-fivem.md)).
2. Vérifie ta connexion internet — un téléchargement incomplet des ressources map peut causer ce problème.
3. Redémarre FiveM entièrement et reconnecte-toi.
4. Si le souci persiste, désinstalle puis réinstalle FiveM.
5. Si rien ne fonctionne, ouvre un ticket sur le Discord en précisant les éléments manquants (captures d'écran utiles).
