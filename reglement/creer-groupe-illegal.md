# ⛓️ Créer un Groupe (Illégal)

Afin de créer votre organisation illégale, il vous faut tout d'abord constituer un dossier puis ensuite ouvrir un ticket sur le Discord.

## VOICI LES CONDITIONS :

Pour toute création ou reprise d'un groupe illégal, les conditions suivantes doivent impérativement être respectées :

* Effectif minimum de **5 membres**.
* Créer une idée de projet illégal exceptionnel si vous ne choisissez pas un groupe prédéfini.
* Fournir un document ou une présentation (Google Doc / Google Slides) détaillant le projet, avec des images si possible.
* Fournir le lore du groupe ainsi que le background de chaque membre dans le dossier.

## Procédure

1. Rassemblez votre équipe (5 membres minimum).
2. Préparez le dossier complet (lore, background des membres, projet illégal détaillé).
3. Ouvrez un ticket sur le Discord officiel InfinityRP dans la catégorie dédiée à la création de groupe.
4. Attendez la validation du staff avant tout début de RP lié à ce groupe.
